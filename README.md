
# Student Supplies Ordering System

## Project Description
A simple browser-based ordering system developed
for IT415 Midterm Practical Examination.

The application allows customers to purchase
school supplies, manage quantities, calculate
totals, pay using cash, and receive a digital receipt.

## Technologies Used
- HTML
- CSS
- JavaScript
- Visual Studio Code
- Git and GitHub

## Available Products
- Ballpen - PHP 12.00
- Pencil - PHP 10.00
- Notebook - PHP 35.00
- Yellow Pad - PHP 45.00
- Eraser - PHP 8.00
- Ruler - PHP 15.00

## System Features
- Display available school supplies
- Add products to the shopping cart
- Increase or decrease quantities
- Remove selected products
- Automatically calculate subtotals and totals
- Validate cash payments
- Calculate customer change
- Generate a digital receipt
- Start a new transaction

## How to Run
1. Download the project from GitHub.
2. Open the project folder using VS Code.
3. Open index.html in your browser.
4. Add products to your cart.
5. Adjust quantities if needed.
6. Enter your cash payment.
7. Click Confirm Payment.
8. View the generated receipt.
9. Click New Transaction to start again.

## Database
This application does not require MySQL
or any other database.

Product information is stored in JavaScript.
